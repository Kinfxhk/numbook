常見問題

為甚麼某些行沒有答案？
Numbook 寧願不答，也不會猜。含運算符但無法解析的行（例如 4300 X 30%， 大寫 X 不是乘號）會留空；日期格式不正確的行亦不當作算式。改成 4300 * 30% 就會計算。
答案怎樣加總？
# 標題 開新的一段，total 會加總該段；total of #tag 加總有該標籤的行。空白行只是間距，不會分段。
貨幣換算的匯率從哪來？
歐洲央行參考匯率（經 frankfurter.app）。設定可關閉自動更新；離線使用快取或內建匯率。 手動按「更新匯率」仍會連網。匯率只供參考，不是交易報價。
記事存在哪裡？會不會上傳？
只存在你的裝置上，不會上傳。詳見隱私政策。
App Store macOS 版有甚麼不同？
付費下載、一次性購買，沒有訂閱。Mac 版加入選單列入口、可設定全域快捷鍵（預設 Control＋Option＋N）、 獨立快速計算草稿與小窗置頂。GitHub Basic 保留計算、記事及一般匯出功能。
快速小窗如何儲存與退出？
快速草稿會在本機自動保存，按 Save note 才另建記事。關閉視窗會保留選單列； 選單 Show Numbook 返回主窗，Quit 才退出。快捷鍵被佔用時可在 Keyboard Shortcut 設定停用或更改。
如何刪除或備份記事？
先以「另存副本」或匯出備份，再從側欄刪除記事。移除 macOS app 可能保留容器及偏好； 如需完整清除本機資料，請先備份並透過下方電郵索取指引。
紙張／答案精度在哪裡設定？
設定 → 外觀可選空白、單線、雙線及目前列底色；設定 → 編輯可選 Auto／2／4／8／完整精度。 顯示四捨五入不改內部計算值；答案選單可分別複製畫面值及完整值。
支援哪些平台？
Android、macOS、Windows、Linux 及網頁版（離線可用）。 各平台的計算引擎相同，答案一致。
